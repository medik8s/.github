## OCP 5.0 upgrade tests

Each job runs once a day on a fresh cluster and upgrades from a GA operator release.
Source jobs build the operator's `main` branch into an FBC. Downstream FBC jobs
select the latest complete public Konflux catalog build. Both run the
`tier:upgrade-operator` tests from `openshift/rhwa-system-tests` main.

All times below are UTC. Click a badge for run history, logs, and reports.
